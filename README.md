Описание директорий
components/ — переиспользуемые UI-компоненты (например, хедер, футер, модальные окна), встречающиеся на нескольких страницах.

elements/ — кастомные обёртки над элементами с методами click(), fill(), get_text() и т.п.

pages/ — классы страниц (Page Object), содержащие локаторы и действия.

fixtures/ — подготовка и очистка окружения (запуск/остановка браузера, авторизация, тестовые данные).

tools/ — утилиты: работа с API, БД, генерация данных, логирование.

tests/ — тестовые сценарии, сгруппированные по функциональности.
